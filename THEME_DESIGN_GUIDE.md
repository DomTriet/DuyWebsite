## 🎬 Animation Comparison

### Eco-Green
**Speed**: Medium-Fast (300-700ms)
**Style**: Natural, flowing, organic
**Easing**: ease-out, cubic-bezier
```
Cards: staggered cascade (100ms apart)
Leaf: infinite float (3s cycle)
Hover: smooth lift effect
```

### Luxury
**Speed**: Slow-Deliberate (500-800ms)
**Style**: Sophisticated, refined, premium
**Easing**: cubic-bezier(0.25, 0.46, 0.45, 0.94)
```
Text: fade-up revelation (200ms apart)
Border: gold accent appear
Hover: subtle lift with glow
```

### Minimalist
**Speed**: Fast-Subtle (300-400ms)
**Style**: Minimal, functional, smooth
**Easing**: ease-out
```
Cards: light stagger (80ms apart)
Hover: underline expand
Underlines: smooth growth
```

## 📱 Responsive Behavior

### All Themes
```
Mobile (< 640px):
├─ Single column layouts
├─ Full-width images
├─ Stacked property cards
└─ Simplified navigation

Tablet (640px - 1024px):
├─ 2-column grids
├─ Medium image sizes
├─ Partial navigation
└─ Balanced spacing

Desktop (> 1024px):
├─ 3-4 column grids
├─ Large hero sections (h-screen)
├─ Full navigation
└─ Generous whitespace
```

## ✨ Interactive States

### Button States
```
Normal:    [BUTTON]
Hover:     [BUTTON ▲] (lift, shadow)
Active:    [BUTTON ▼] (pressed)
Focus:     [BUTTON] (outline/ring)
Disabled:  [BUTTON] (opacity: 50%)
```

### Link States
```
Normal:    Link Text
Hover:     Link Text ← underline appears
Focus:     Link Text ← ring outline
Visited:   Link Text ← same as normal
```

### Card States
```
Normal:    ┌─────────────┐
           │   Card      │
           └─────────────┘

Hover:     ┌─────────────┐
           │   Card ↑    │
           │  (shadow)   │
           └─────────────┘

Focus:     ┌─────────────┐
           │ ▲ Card ◆    │ (ring)
           └─────────────┘
```

## 🎯 Key Design Decisions

### Why Three Themes?

1. **Eco-Green**: 
   - Appeals to environmentally-conscious buyers
   - Natural, trustworthy aesthetic
   - Perfect for eco-developments, green buildings

2. **Luxury**:
   - Attracts high-net-worth individuals
   - Premium feel, exclusive positioning
   - Ideal for luxury properties, high-end projects

3. **Minimalist**:
   - Universal appeal, content-first
   - Fast loading, accessible design
   - Works for all property types, professional market

## 🔧 Implementation Benefits

✅ **Consistent across all themes:**
- Same data structure (properties, agents, forms)
- Identical functionality (favorites, sharing, filters)
- Same backend API calls
- Unified SEO approach

✅ **Distinct visual identities:**
- Different color palettes
- Unique typography systems
- Theme-specific animations
- Customized component styling

✅ **Performance optimized:**
- CSS animations (GPU-accelerated)
- No additional dependencies
- Minimal bundle size increase
- Fast render times
